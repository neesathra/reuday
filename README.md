# Chapter 22: Still Growing With You

A romantic, responsive birthday website made with plain HTML, CSS, and JavaScript.

## Preview locally
1. Download and unzip this folder.
2. Open `index.html` in your browser.
3. Internet access is needed for the Google Fonts and Spotify music embed.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `chapter-22`).
2. Upload **all contents** of this folder, keeping the `assets` folder intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub to publish the site. The Pages URL will appear in that section.

## Customize
- Replace `assets/our-photo.png` with another image using the same filename if desired.
- The song is embedded from Spotify. Visitors may need to tap Play and Spotify may require a login depending on their device/account.
- The website is static; no server or paid hosting is required.
